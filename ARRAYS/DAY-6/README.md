# Problems Solved

## 1. Reverse an Array Using Two Pointers

Reverse the array by using two pointers, one starting from the beginning and the other from the end, and swap the elements until both pointers meet.

**Note:** The two-pointer technique reverses the array efficiently without using an extra array.

## 2. Frequency of an Element in an Array

### a) Sorted Array

Find the frequency of a given element in a sorted array by traversing the array and counting its occurrences.

### b) Unsorted Array

Find the frequency of a given element in an unsorted array by checking each element and counting the number of times it appears.
