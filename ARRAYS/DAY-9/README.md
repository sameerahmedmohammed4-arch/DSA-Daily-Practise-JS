# Day 9 - Arrays

# Problems Solved

## 1. Maximum Subarray Sum (Brute Force Approach)

Find the maximum sum of all possible contiguous subarrays by checking every subarray and comparing their sums.

**Note:** This approach examines all possible subarrays to determine the maximum sum.

## 2. Maximum Subarray Sum (Kadane's Algorithm)

Find the maximum subarray sum by traversing the array only once and maintaining the maximum sum ending at the current position.

**Note:** Kadane's Algorithm is an optimized approach that efficiently finds the maximum subarray sum.

## What I Learned

* How to generate and evaluate all possible subarrays.
* Difference between brute force and optimized solutions.
* How Kadane's Algorithm works for maximum subarray sum.
* Improved understanding of optimization techniques and array traversal.
