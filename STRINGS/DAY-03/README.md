# Problems Solved

## 1. Valid Anagram

Check whether two given strings are anagrams of each other by comparing their characters and their frequencies.

**Example:** `listen` and `silent` are valid anagrams.

**Note:** Anagrams contain the same characters with the same frequency, but the order of characters can be different.
