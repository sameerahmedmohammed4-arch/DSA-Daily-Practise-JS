# Day 10 - Arrays

# Problems Solved

## 1. Rotate Array Left and Right by One Position

Rotate the elements of an array by one position either to the left or to the right while preserving the order of the remaining elements.

**Note:** A single rotation shifts each element by one position in the chosen direction.

## 2. Rotate Array Left and Right by K Positions

Rotate the elements of an array by **k** positions to the left or right.

**Note:** Multiple rotations can be optimized by using the value of `k` relative to the array size.

## What I Learned

* How array rotation works in both left and right directions.
* Difference between one-position and k-position rotations.
* How to handle rotations efficiently for different values of `k`.
* Improved understanding of array manipulation and indexing.
