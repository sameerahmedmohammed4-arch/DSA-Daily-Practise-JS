# Day 12 - Strings

# Problems Solved

## 1. Check Whether a Word is a Palindrome

Check whether a given word reads the same forward and backward.

**Examples:** `madam`, `mam`, `mom`, `level`, `radar`, `noon`, `civic`, `refer`.

**Note:** Practiced comparing characters from both ends of a string.

## 2. Count Frequency of Each Word

Given a string containing multiple words separated by spaces, count how many times each word appears and store the result in an object.

**Note:** Used an object to store each word and its frequency.

# What I Learned

* How to check whether a string is a palindrome.
* How to compare characters from both ends.
* How to count word frequencies.
* How to use JavaScript objects for storing key-value pairs.
